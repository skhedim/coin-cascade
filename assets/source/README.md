# Sources artistiques

Première livraison : `ART-001-face-piece-et-fonds/`, avec originaux générés, prompts exacts, exports contrôlés et vérifications. Voir son `README.md` et la demande correspondante dans `../../docs/art/requests/`.

Seconde livraison : `ART-002-decal-mur-et-piece-doree/`, avec les sources du décal 8:3 et de la pièce étoilée, les prompts exacts, mesures, comparaison visuelle et contrôles navigateur.

Pour une livraison, créer un sous-dossier par demande, par exemple `ART-001-classic-coin/`, contenant les sorties d'origine, variantes utiles, gabarit reçu et notes. Conserver le fichier original avant redimensionnement ou compression.

Les exports réellement chargés par le jeu vont dans `../../public/assets/`, aux chemins du manifeste. Ce dossier de sources n'est pas automatiquement publié dans `dist/`.
